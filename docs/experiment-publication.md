# 数据集与实验记录的公开分工

Hugging Face 发布可复用的数据集；GitHub 发布执行方法及每次实验的结果和运行证据。运行记录是公开交付的一部分，不只保存在组织者本机。

| 平台 | 公开内容 |
|---|---|
| Hugging Face | 公开题面、任务类型、阶段结构、逐题评分细则、评分通则、版本化子集清单及哈希 |
| GitHub 仓库 | 执行代码、配置示例、实验协议、使用说明，以及每次实验的范围、配置、逐题结果、评审状态和证据索引 |
| 同一 GitHub 项目的 Release 附件 | 对应该次实验的脱敏答卷、执行轨迹、工具调用、日志、失败和重试记录、来源与用量记录；附件名和校验哈希由仓库索引关联 |

## 第一次公开实验

第一次实验是 **一个包含 20 道题的子集**，选题清单为 `public-dev-20-v1`。它包含 20 个案例、24 个作答阶段；不是 20 个子集，也不是整个公开题库已经完成测评。两阶段题只计一道题，重复尝试不增加题数。

当前[九配置评分报告](../experiments/subset20-results-nine-final-20261010/README.zh-CN.md)包含Astra、Sol、DeepSeek、Gemini 3.1 Pro、Gemini 3.8 Flash、Kimi、Qwen、GLM 5.3 Flash（Ark Managed Agent）和Claude Code（Opus 5.5）。各完成20份初评，共180份评审；统一应用院系勘误后，180份确定分数、无阻塞评分的待核节点。Claude的20题均分为73.14，GLM均分为68.91；Gemini 3.8 Flash的校内资格项由待核改为半分，该题64.5分、20题均分60.56，DeepSeek语言项按负责人裁决为5/10分，均分69.23；DAAI六级资格仍未证实而不阻塞这一评分裁决，其余成绩保持不变。以下r2运行包仍为七配置，新增两配置原始记录尚未合入附件。

Qwen新增6份单阶段答卷采用超时后基于既有记录开启新会话的续作方式，并延长执行时限，不是原生会话恢复。4道两阶段题另行执行，其中3题遭遇账号访问错误；账号恢复后，2题从已保存的第一阶段原生会话接续，1题重新开始，原失败和完成阶段均保留。BY-H-APPLY的首个评审超时且无最终判断，使用相同输入和评审配置另行补跑，没有替换已有分数。

r2运行包已补齐Qwen的20题答卷、轨迹、原失败和补跑记录，并核对评分输入哈希；原六配置答卷和轨迹保持不变；执行表统一关联评分，七配置的调用与用量汇总包含千问补充执行并去重恢复阶段。历史r1和此前报告保留，r2附件尚未上传。r2内绑定的是勘误前129份确定、11份待核的初评版本；最新更正分数见当前报告，不改写原附件。

首次可以公开这一带明确状态的实验快照，无须把待核结果包装成最终排名。完整均分与排名须等相关评分项完成统一裁决；题库教师校准与本轮模型答卷终审是不同的状态。

## 每次实验保留什么

- 选题清单、题面和评分版本、客户端和模型配置、认证模式、工具与隔离条件。
- 全部预期题目位置的完成、失败、未执行和评审状态，以及可公开的实际答卷。
- 已结束执行的轨迹、工具调用、日志、尝试历史和最终选中答卷的来源；复用不冒充新调用。
- 逐题结果、待核项和评分证据的版本绑定；结果快照与执行记录快照分别注明时间，只有来源哈希一致时才能关联。
- 已记录的用量及其统计范围；未知用量或费用保留为空，不填写为零。
- 公开附件清单、原始文件与脱敏副本的哈希、脱敏说明。

原始文件保留供审计；公开副本移除凭据、登录状态及个人联系方式等敏感字段，不借脱敏改写答案或隐藏失败。大体积轨迹使用 GitHub Release 附件，仓库保留稳定索引。下一次实验或更晚的结果更新生成新快照，不覆盖第一次记录。
