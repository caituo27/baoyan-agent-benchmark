## 与当前200题库的关系

## 使用边界

本清单供组织者选题，不作为被测 Agent 输入；评分文件、参考清单和后续阶段不能提前进入答题上下文。两阶段任务按 S0→S1 顺序在同一会话释放，仍作为一道原题计分。

50题实验须以本清单固定报告分母，与20题、40题及75题结果分别报告。已有答卷仅在输入、模型配置、协议和采集完整性相容且核验通过时复用，不能按分数挑选尝试。
