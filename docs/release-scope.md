# 发布范围

当前题库为**75道公开dev＋125道私有test＝200题**。公开开发集包含61道单阶段题、14道两阶段题，共89个作答阶段；4条连续案例复用原题，不增加题量。公开范围由[75题清单](public-subset-75.md)确定，私有题面、细则和来源记录保存在仓库之外。

## 导出公开包

```sh
python3 scripts/prepare_publication.py --out dist/publication-YYYYMMDD-N
```

命令生成两个本地目录：`huggingface/` 保存75题数据及评分资料，`github/` 保存75题公开源码副本和实验记录。目标目录必须不存在，命令不调用模型或上传。

导出按题号清单过滤历史源池，保留入选题面与rubric字节，重新绑定集合清单及其依赖哈希。原始评审底稿、内部工作记录、凭据和本地配置不属于发布内容。经审查的脱敏答卷及轨迹作为实验附件分发；目录结构和复核要求见[发布说明](publication.md)。

公开评分资料只供评审使用，不进入被测Agent输入；未来阶段必须按顺序释放。

## 历史打包接口

旧版命令与数据格式见[历史版本说明](historical-workflows.md)。新发布使用上面的75题导出入口。

## 公开授权记录

`release/public-review.json`和`release/hf-review.json`保留历史题库的公开授权及内容指纹；它们不扩大当前75题发布范围。前者绑定两类dev、演示题和连续目录，后者不含演示题。内容变更后须重新审核，不能将旧授权自动用于新题目。

记录使用 public-release-review.1 格式，包含 reviewer、reviewed_at、catalog_sha256 和 tasks。每题记录包含 fingerprints（task、rubric）、privacy_approved、redistribution_approved 与 reason。记录只保存公开结论，不包含私人证据或联系方式。

校验器检查记录与数据的一致性，不认证审核者身份，也不代替内容评审或教师校准。全200题教师校准已由负责人确认完成，见[当前审核状态](../release/publication/review-status-200.json)；冻结题目的历史字段保留用于版本追踪。

## 版本与复现

运行记录固定题目、评分规则、协议、所选配置与相关代码指纹。代码或数据变化后使用新运行目录；已有结果应使用匹配的发布版本复核。完整发布指纹用于溯源，运行与评分组件指纹用于判断兼容性。

CLI 的本地凭据与个人配置不属于发布内容。答卷及原生日志可能包含敏感信息，必须保存在公开仓库之外或被忽略的本地目录中。
