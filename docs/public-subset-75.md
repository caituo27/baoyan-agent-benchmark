# 75题公开开发集

发布清单：`config/selections/public-dev-75-v1.json`。总题库为75道公开dev＋125道私有test，共200题。公开集包含61道单阶段题（23择校推荐、38规划决策）、14道两阶段题，89个作答阶段、24个匿名学生案例组。

20题、40题和历史50题都是这75题内的评测选择，不额外增加题库数量。首批实验采用固定20题、9个配置（含千问、Claude Code和GLM），共180份初评，见[当前结果](../experiments/subset20-results-nine-final-20261010/README.zh-CN.md)。[r2执行记录](../experiments/subset20-20261009-r2/README.md)仍为七配置附件。题面与rubric属于组织者资料；被测Agent只能收到当前阶段的候选输入。

## 执行本题集

配置客户端后，使用 `python3 -m benchmark cli-batch --selection config/selections/public-dev-75-v1.json --agent gpt-6-1-sol --out ./runs/codex-dev75 --execute`。去掉 `--execute` 可先预览；每配置、每次重复为75题、89阶段。评分与报告步骤见[使用指南](quick-start.md)，将其中dev20目录统一替换成这次的dev75目录。每个题集使用新目录、分别报告，不能与20题均分混排。

## 私有125题

4道上述题目＋121道依据现有题目和部分评审结果逐题新编的情景题，均配专属评分细则。私有题面、细则、作者稿与来源关系全部保存在公开仓库之外；公开资料只披露数量、来源性质和评审状态。

本次新编题全部是单阶段任务，采用现有规划/决策评分接口，细分澄清、资格、证据、材料、研究、准备、计划、方向决策和答复审查等任务。它们沿用现有24个案例背景，不是121个新增真实学生，也尚不构成独立holdout。负责人现已确认全200题（含121道新编题）的教师校准完成。当前状态见`release/publication/review-status-200.json`；冻结pending元数据不代表当前未完成，独立性及实际评测结果另行记录。
