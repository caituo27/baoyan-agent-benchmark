先直接给结论，再说依据。

**在"新比赛 / 现有科研 / 专业面试"这三者里，你的主要精力应该放在【专业面试（含机试）】上，【现有科研】紧随其后，【新比赛】优先级最低、基本可以放弃。**

## 为什么是这个排序

你的硬背景（8/175、六级588、ICPC/CCPC 奖项）已经足以通过清北华五港三的**简历初筛**，属于强档。真正决定你能否上岸、以及能不能选到好导师的，是初筛之后的东西：机试 + 面试，以及科研潜力能否被讲清楚。

- **排名已成定局**：8/175 是前 4.6%，这个位置每年变化不大，再刷绩点的边际收益极低。
- **你缺的短板不是"奖不够多"**：ICPC/CCPC 的边际收益已经很低，再加一个区域赛奖牌，对招生老师的信息增量接近于零。真正刺眼的是"没有正式论文"——而这是短期最不可控的。
- **面试和机试是短期最可控、且权重最高的**：清北华五的机试/笔试往往直接卡人（不少区域赛选手也会因为时间分配和题型不熟翻车），面试则决定导师愿不愿意带你。

## 建议的精力分配（以总精力 100% 计）

| 方向 | 占比 | 具体做什么 |
|---|---|---|
| 面试 + 机试 | 45–55% | 按目标校历年机试题/笔试大纲刷题；准备"专业基础面"（数据结构、算法、操作系统、数学）+ 科研追问；控制硬件的口头表达 |

| 新比赛 | 0–5% | 除非是时间极短、性价比极高的短赛，否则不投入 |

## 关于"现有科研"：重点不是发论文，而是"讲得深 + 有交付物"

时间不够、又没论文，最优解往往不是再冲一个 deadline（周期长、风险高），而是把现有科研做成**能被验证的东西**：

- 一份结构完整的技术报告 / 预印本（哪怕未正式发表）；
- 能跑通、有 README 和实验记录的开源代码仓库；
- 复现结果、数据集、benchmark 对比。

面试时老师追问的通常不是"发在哪"，而是：你为什么这么设计？baseline 是什么？瓶颈在哪？如果重做会怎么改？**能把这些讲透，比多一篇水论文更打动导师。** 你的 ICPC 背景正好可以用来证明"能把想法实现出来"。

## 港三要单独打

内地保研（夏令营/预推免）拼的是机试+面试+排名；港三研究型（MPhil/PhD）拼的是**导师匹配度**。你的英语 588 够用、编程能力是明确加分项，但需要主动发邮件套磁，附上简历、代码/报告链接，说明你能为导师的课题做什么。港三申请时间线通常更早，别等到内地推免结束才动手。
