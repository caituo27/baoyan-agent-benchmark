# 2026年9月：从"拿资格"切换到"拿接收"

先明确你现在的位置：推免资格已经到手（哪怕是递补），**接下来决定结果的不再是 GPA 和加分，而是信息速度、材料质量和面试表现**。2027届推免服务系统的时间线已经很清楚：

- **9月18日起**注册、填报个人资料、查看本人推免资格
- **9月21日 9:00** 起填报志愿（**3个平行志愿，每个提交后锁定48小时**）
- **9月22日 8:00** 起确认复试通知
- **9月24日 14:00** 起确认待录取通知
- **10月18日**截止填报志愿，**10月20日**截止确认复试/待录取；**10月20日前未落实接收单位，推免资格失效，可转统考**

来源：[四川省2027年推免公告](https://www.sceea.cn/Html/202609/Newsdetail_4970.html)、[东华大学推免服务系统流程说明](https://yjszs.dhu.edu.cn/2026/0923/c8889a381003/page.htm)。

---

## 一、旧方案里应当"沿用"的

| 沿用项 | 现在怎么用 |
|---|---|
| **英语（六级547）** | 这是你的显性优势。多数院校门槛 425/450/480 你都过线；更关键的是**复试几乎都要英语环节**，把口语和"用英文讲自己的科研项目"练熟 |
| **科研经历的叙事化** | 国家级大创没有正式成果，不等于没用。按"**研究问题 → 方法/技术路线 → 我具体做了什么 → 现在做到哪一步 → 下一步打算**"讲清楚。这正对应能源学院复试要考察的"既往科研经历与成果、未来科研兴趣与规划" |
| **材料准备与联系导师** | 旧方案里"大三下整理材料、联系导师"的动作要继续，并且**优先级大幅提前**（见下节） |
| **学术诚信、不造假** | 复试/资格复核中查实造假会取消资格；大创没成果就如实讲过程，绝不挂名凑成果 |

## 二、必须"调整"的六处

1. **目标变了**：从"争取推免资格"变成"争取招生单位接收"。资格已定型，GPA/加分不再是你现在能改变的东西，**不要再花时间补加分**。
2. **时间尺度变了**：从两年长线，压缩成 **约4周（9/21–10/20）**。旧方案里"夏令营申请（2026年3–6月）"这一环，如果你此前没有拿到意向，现在要跳过，主攻**九推（系统填报阶段）和尚未截止的预推免**。
3. **择校逻辑变了**：从"单一目标（本校）"变成**冲/稳/保梯度 + 3个平行志愿的时间差操作**。3个志愿不区分先后、各自锁定48小时，要用来组合，而不是把三个都押在同一个层次。
4. **大创策略变了**：从"争取出成果"变成"**如实呈现、突出可迁移能力**"（实验技能、表征手段、数据分析、英文文献能力）。成果没出来是常态，面试官更看你能不能把问题讲明白。
5. **目标范围可以适度打开**：从能源学院扩展到**能源/材料/化学/物理/化工/新能源**等对口方向，以及中科院相关研究所（是否接收、有何要求需逐个核实）。同时保留本校作为最稳选项。
6. **风险项新增"统考备选"**：10月20日前若没有落实接收单位，资格失效但可报名统考；而**一旦接受待录取，就不能再报名统考**。所以要有底线思维。

## 三、当前窗口的行动清单（按时间）

**立刻（9月18–20日）**
- 登录[推免服务系统](https://yz.chsi.com.cn/tm)注册、缴费，**确认"本人推免资格"已备案**（递补资格也要在系统里能查到，这一步最关键）。
- 做一份**通用材料包**：盖章成绩单、专业排名证明（20/69）、六级证书、大创立项/中期/参与证明、获奖证书、简历（中英文）、个人陈述、1–2封推荐信。
- 同时启动**本校预报名**：苏州大学能源学院接收推免走的是[苏州大学研究生报考服务系统](http://gsas.yjs.suda.edu.cn)（"全国优秀大学生推免预报名"），**注意它和教务处的"本科生推免申请系统"不是同一个系统**（来源：[能源学院2027年接收推免生综合考核实施细则](https://energy.suda.edu.cn/de/dd/c9469a712413/page.htm)）。
- 给 3–5 位目标导师发套磁邮件（附简历+成绩单+大创简述），问今年是否还有名额、方向是否匹配。

**9月21日 9:00**
- 填报 3 个平行志愿，建议组合为 **1冲 + 1稳 + 1保**（例如：外校对口课题组 / 本校强势方向 / 本校保底或同层次院校）。**越早填越好**，因为很多学院的复试安排是先到先排、名额动态变化。

**9月22日 8:00 起**
- 盯复试通知，按院校要求确认并参加面试。能源学院本校是**线上综合面试，约20分钟**，考察英语水平、专业基础、科研经历、未来规划、综合素质，综合考核成绩60分合格。
- 面试准备清单：英文自我介绍、大创项目双语讲解、2–3个专业基础问题（电化学/材料表征/储能器件等）、为什么选这个方向/导师、读研规划。

**9月24日 14:00 起**
- 查待录取通知。**只能接受一个**；接受后不能再报其他志愿，其他单位也不能再发通知（除非征得学校同意取消待录取，并由你确认）。没到你的"最低可接受线"就谨慎点"接受"。

**9月24日–10月18日**
- 滚动操作：未解锁/被拒的志愿及时补填；继续面试。**10月18日截止填报，10月20日截止确认**。

## 四、结合你画像的"冲稳保"框架

你的画像：**专业排名 20/69（约前29%）、六级547、有国家级大创经历但无正式成果、资格为递补、时间偏紧**。据此建议：

- **冲**：中科院系统对口研究所、中西部985或部分211的"材料—能源—化学"方向。这类单位有时更看研究匹配度和面试表现，但名额动态、需逐个核实并靠套磁争取。
- **稳**：**苏州大学本校**（能源学院、材料与化学化工学部、物理学院等相关方向）——这是你信息最全、概率最高的选项；此外同层次211的能源/材料/化学方向也值得投。
- **保**：本校明确意向并通过复试；或同层次院校中相对冷门的方向。务必给自己留一个"能接受"的底线。

**筛选学校时要核实的事项**：该校该专业**是否还在九推阶段接收**（很多学院官网会像东华那样实时更新"继续招收/名额已满"）、六级/排名门槛、是否必须提前预报名、复试形式（线上/线下）、是否接受专业相近但不完全对口的考生。

另外，**学硕/专硕/直博**要尽快定：你缺少论文成果，**直博的竞争力通常弱于学硕/专硕**；建议以"导师方向匹配度"为核心来选，而不是只盯学位类型。

---

## 五、三条决策原则

1. **底线先行**：先确定"最低可接受"（多数情况下就是本校），把它报进志愿并认真准备复试，避免窗口末尾空手。
2. **48小时锁定要有节奏**：不要三个志愿同时投三个同层次院校，留出解锁后补投的空间。
3. **接受待录取前想清楚**：接受后不能改、也不能统考；不接受则可能到10月20日失去资格。递补资格来得晚不是劣势——很多导师更在意**方向匹配、英文水平和面谈时的研究潜力**，这几项恰好是你能在两周内提升的。
