你可以从现在开始争取保研，而且你这个专业已有推免先例。眼下最值得做的三件事是：**确认自己按哪一届毕业生参加推免、拿到学院的选拔细则、把成绩和英语基础稳住。**你现在大二上，主要处于积累阶段，不需要马上参加毕业生的推免报名。

以下按你设定的**2024年10月**来说明。政策依据采用这个时间点之前已发布的官方材料；其中“2025年推免”指2024年秋季选拔、2025年研究生入学，不是你现在就要报名。

**先理解保研要完成哪两个环节。**

通常所说的“保研”，正式名称是推荐优秀应届本科毕业生免试攻读研究生，简称“推免”。“免试”主要是免去全国硕士研究生招生考试的初试，接收院校仍会进行材料审核和复试。

可以把整个过程理解为：**苏大推荐你 → 目标院校考核并愿意接收你 → 在全国推免系统完成确认 → 按期毕业、入学。**

- **推荐资格由本科所在学校决定。**你要参加苏大能源学院的校内遴选，在相应专业的名额内入选，经过学校审核、公示和备案。
- **研究生录取由接收院校决定。**有了资格，仍要申请具体学校、学院和专业，接受其考核；可以考虑本校，也可以考虑外校，具体须符合接收要求。
- **夏令营、预推免是提前选拔机会。**“入营”只是获得参加活动的机会，“优秀营员”或预录取的效力要看通知。它们不能替代母校推免资格和全国系统的正式手续。

苏大校级文件明确了校内申请、学院评价、学校审核以及全国系统报考的衔接；研招网也明确，未在系统确认接受待录取通知，录取不生效。[苏大《推免工作实施办法（2021年修订）》](https://jdxy.suda.edu.cn/_upload/article/files/89/d8/f911fb7b47e3868f80bf08130492/16f196da-f32b-4b20-9622-8ee79f1bdf2d.pdf)、[研招网2025推免系统操作流程（2024年9月发布）](https://yz.chsi.com.cn/kyzx/kp/202409/20240921/2293140449.html)

**你的中外合作办学身份，不意味着没有推免机会；但毕业年份必须先确认。**

能源学院2024年9月18日公布的2025年推免初选名单中，明确列出了“新能源材料与器件（中外合作办学项目）”的入选学生。因此，可以确认这个专业存在校内推免通道。你本人最终是否能取得资格，还要看届时的学籍、毕业安排、成绩和选拔结果。[能源学院2025年推免名单公示](https://energy.suda.edu.cn/26/11/c9469a599569/page.htm)

这个专业的时间安排需要特别注意：苏大国际合作交流处2023年公布的项目资料标注**学制五年、允许学习年限4—9年**，项目涉及加拿大维多利亚大学；同页培养方案还出现四年与五年的不同表述。另一方面，2024年推免公示中有学号以“21”开头的该专业学生。这提示实际毕业安排可能存在差异，不能仅凭专业名称，断定你一定在大四或大五参加推免。[官方项目与培养方案](https://international.suda.edu.cn/bc/c5/c12655a310469/page.htm)、[2024年推免公示](https://energy.suda.edu.cn/26/11/c9469a599569/page.htm)

如果你是2023年入学，可先用下面两个情形安排准备；这只是根据毕业年份作出的时间推算，不代表已经确认你能选择哪一种路径：

| 经教务确认的毕业安排 | 主要申请季通常落在哪一年 | 研究生入学年份 |
| --- | --- | --- |
| 2027年本科毕业 | 2026年春夏至秋季 | 2027年 |
| 2028年本科毕业 | 2027年春夏至秋季 | 2028年 |

判断依据应是学校认可的**应届毕业生身份和预计毕业时间**。若考虑赴加学习，还需提前确认国外课程如何转换学分和成绩、怎样纳入推免排名、能否在接收院校要求的期限前取得本科毕业证与学位证，以及境外期间如何完成申请和考核。

**资格方面，可以先拿2024年发布的能源学院细则作对照。**

该细则适用于2025届学生，你可以用来建立准备方向，不能把它当作你毕业那一届的保证：

| 项目 | 这轮细则的要求 |
| --- | --- |
| 身份 | 国家普通本科招生计划录取的应届本科毕业生，第二学士学位专业学生除外 |
| 品行 | 符合思想政治、纪律和诚信要求，无学术不端等问题 |
| 课程与学分 | 已修课程均达到合格标准；已取得毕业所需学分至少75%；申请时必修课没有弃考记录 |
| GPA | 至少3.2 |
| 英语 | 六级至少425分，或四级至少480分 |

这些是**申请门槛**。达到门槛后还要竞争名额，不能理解为“GPA到3.2就能保研”。该轮中外合作专业普通名额为10个；没有你这一届的名额、排名人数和成绩情况，目前无法判断你的成功概率。[能源学院2025年推免实施细则，2024年9月发布，见第二、四部分](https://energy.suda.edu.cn/_upload/article/files/c6/ce/2b053b2743ec84e316d73a1715d7/41fe59db-0712-4efe-914c-91b121f67d19.pdf)

不要把别的学院或网上经验帖的英语线、GPA线直接套给自己。如果已有挂科、补考或重修，应向教务办核实成绩认定和排名处理方式；上述要求是申请时课程合格，不能据此自行推断“曾经挂过科就永久失去资格”，也不能假定重修后所有影响都会消失。

**准备的优先顺序：成绩和英语先打底，再做有真实贡献的科研、竞赛。**

学院这轮采用“GPA×100＋发展素质分”的综合评价，总分500，按专业排序。发展素质五项上限分别是：服兵役20、志愿服务10、国际组织实习10、科研30、竞赛30；科研与竞赛各自取最高单项，不能无限累加。志愿服务累计18至不足36小时对应5分；满36小时对应10分，并须满足学业奖学金评定的相关时长要求、经学院认定。竞赛计分限定在两类“挑战杯”、中国“互联网＋”大赛、全国大学生节能减排社会实践与科技竞赛等细则列出的四项赛事，还要满足获奖等级、团队排名和参赛单位要求。[能源学院2025年推免实施细则，第四部分](https://energy.suda.edu.cn/_upload/article/files/c6/ce/2b053b2743ec84e316d73a1715d7/41fe59db-0712-4efe-914c-91b121f67d19.pdf)

这轮学业分使用教务处公布、保留一位小数的GPA；总分相同时先比较该学业分，再比较保留三位小数的GPA。因此，自己估算只能帮助规划，正式排名要以学院认定结果为准。[学院细则，第四部分](https://energy.suda.edu.cn/_upload/article/files/c6/ce/2b053b2743ec84e316d73a1715d7/41fe59db-0712-4efe-914c-91b121f67d19.pdf)

这对你有几个实际含义：

- **先查自己的专业排名。**关注累计GPA、哪些课程计入推免成绩，以及排名比较的是中外合作专业全体学生还是其他范围。把高学分课程、薄弱课程列出来，优先改善它们。GPA是按学分计算的，不宜简单把所有课程分数作算术平均。
- **英语尽早达标，再提升实际能力。**如果四级尚未达到上述参考线，先解决；能参加六级就及早准备。之后持续练习专业文献阅读、英语自我介绍和研究经历表达。目标院校可能有自己的英语要求，校内达标不等于所有外校都达标。
- **科研从一个能长期做的小任务开始。**可向班主任、本科生导师或课题组咨询本科生参与机会，例如文献梳理、材料制备、性能测试、数据分析。先学实验安全和记录方法，逐步争取大创等项目。你应能讲清研究问题、自己的工作、结果和不足。
- **竞赛先核对认定范围，再决定投入。**数学建模、英语竞赛等可能锻炼能力，但不能自动算成这轮能源学院推免加分。报名之前核实赛事、获奖层级、本人排序和成果截止日期。
- **保存证明材料。**志愿服务记录、项目立项及中期或结题证明、获奖证书、论文或专利材料，都应及时归档。科研项目仅仅立项，或论文仅有投稿记录，是否符合计分条件，需要逐项对照文件。

不必把“发一篇论文”当作保研的必经步骤。2024年的公示中，该专业也有科研、竞赛得分均为零的普通推免入选学生；这说明论文并非这轮普通推免的必备条件，但不代表无成果就一定能入选。[学院推免公示](https://energy.suda.edu.cn/26/11/c9469a599569/page.htm)

**临近申请时，通常按以下节奏推进。**

| 阶段 | 需要做什么 |
| --- | --- |
| 现在至申请季前 | 稳定成绩与英语，探索研究方向，积累项目经历和证明材料 |
| 毕业前一年的春季至夏季 | 查目标院校夏令营通知，按各自截止时间提交材料、参加活动及考核 |
| 同年暑期至9月 | 关注预推免，补充申请；同时办理苏大校内推免申请，两边都要跟进 |
| 同年9月至10月 | 在母校资格确定后，按全国系统和接收院校要求填志愿、确认复试及待录取 |
| 本科毕业至研究生入学 | 完成课程与毕业论文，按期取得毕业证和学位证，配合录取资格复查 |

这是常见节奏，各校可能提前或合并考核。举例说，南京大学能源与资源学院2024年夏令营面向2025年毕业的相关专业本科生，新能源材料与器件相关背景可用于研究方向衔接；你可以先读这种通知了解要求，正式申请时必须核对是否招收你的毕业届别。[南京大学2024年夏令营通知](https://eng.nju.edu.cn/7f/e6/c4968a688102/page.htm)

还要分清三个系统：

- **苏大本科生推免申请系统**：申请母校推荐资格，2024年公布的网址为[http://tmsq.jwb.suda.edu.cn](http://tmsq.jwb.suda.edu.cn)。
- **目标院校自己的报名系统或指定渠道**：申请夏令营、预推免等。若申请留在苏大，按研究生院通知使用[苏大研究生报考服务系统](http://gsas.yjs.suda.edu.cn)。
- **教育部全国推免服务系统**：完成正式报考和接收确认，入口为[研招网推免系统](https://yz.chsi.com.cn/tm/)。

上述三个系统的用途由苏大2024年发布的通知明确区分。2025年这轮全国系统操作允许同时填三个平行志愿，但只能接受一个待录取通知；接受后不能继续填报其他志愿或接受其他复试、待录取通知，所以最终确认前应想清楚。你申请那年的时间和操作要求须重新核对。[苏大2024年通知中“关于推免的三个系统”说明](https://jdxy.suda.edu.cn/22/54/c12042a598612/page.htm)、[研招网2025操作流程](https://yz.chsi.com.cn/kyzx/kp/202409/20240921/2293140449.html)

正式申请常用材料包括：盖章成绩单与排名证明、英语成绩证明、简历、个人陈述或研究计划、学籍及身份证明、项目与获奖材料；有些院校另要专家推荐信。现在建立电子文件夹即可，临近申请再按各校要求取得最新盖章版本，不必提前几年把所有证明开齐。

**你现在可以用一周把第一步做扎实。**

1. **找辅导员和本科教务办确认毕业届别。**说明自己是2023级中外合作专业，问清留国内与赴加两种安排对应的毕业年份、推免年份、成绩转换和排名办法。
2. **保存三类文件。**校级推免办法、能源学院最新推荐细则与名额通知、你所在年级培养方案。每年更新一次，临近申请时更密切关注。
3. **做一张个人情况表。**记录累计GPA、专业排名及总人数、已获学分、四级和六级成绩、未合格课程或弃考情况，以及已有科研、竞赛、志愿服务记录。先找出最急迫的缺口。
4. **安排本学期的两个明确目标。**一个是成绩或英语目标，另一个是了解并尝试一个科研方向。暂时不用参加大量活动填满简历。

你可以直接把下面这段发给老师咨询：

> 老师您好，我是2023级新能源材料与器件（中外合作办学）学生，目前大二，想了解推免准备。请问我所在年级留国内或赴加学习分别按哪一年应届毕业生参加推免？能否提供适用的培养方案、学院推免细则，以及GPA统计和专业排名口径？另外想确认补考重修、境外成绩转换和英语成绩的认定要求。谢谢老师。

政策问题优先找本科教务办、学院推免工作小组；学长学姐适合补充经验。学院2024年推免文件公布的联系渠道为**0512-67164098、[REDACTED_EMAIL]**，可用于询问应联系哪位本科教务老师。[学院2025年推免细则，联系渠道](https://energy.suda.edu.cn/22/5b/c9469a598619/page.htm)

选校方面，先从你更喜欢的研究问题入手：电池与储能材料、太阳能电池、催化与氢能等，再查材料、化学、能源相关学院的专业目录、导师方向和接收条件。学硕、专硕和直博要分别看培养安排；大二阶段可以先探索，尤其直博应在了解科研生活后再作决定。

若国内推免和境外深造都在考虑，可以先了解两条路径，但正式申请前要核实承诺要求。苏大2021年办法对获得推免资格后另行择业、申请境外高校留学作了约束；这与你的合作办学规划有关，应请学院明确解释。[校级办法第十二条](https://jdxy.suda.edu.cn/_upload/article/files/89/d8/f911fb7b47e3868f80bf08130492/16f196da-f32b-4b20-9622-8ee79f1bdf2d.pdf)

你现在不需要先证明自己“肯定能保研”。先确认毕业路径，掌握本专业的规则，用每学期的成绩和英语进展检查差距，就能把这个目标变成可执行的准备。
