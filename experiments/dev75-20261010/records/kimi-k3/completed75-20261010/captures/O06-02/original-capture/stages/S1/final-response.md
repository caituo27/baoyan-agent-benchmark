# 结论：大方向不变，但科研部分的用法要改——从"推进结果"改成"整理叙事"

## 调整后的分配：约 6.5 : 2.5 : 1（面试 : 科研梳理 : 代码手感）

新信息带来的关键变化是：**两段科研都卡在"调试方法"阶段**。这类工作的特点是时间黑洞——方法调不通可能是一周，也可能是三个月，周期完全不可控。在时间紧张、申请时点未知的情况下，继续往里面填时间的期望收益很低。

## 具体建议

**1. 三段科研的角色重新定位（这是本轮最重要的调整）**
- **挑一段最完整的当主线**：哪怕是暂停的那段，只要问题定义清楚、你做过扎实的工作、能讲出"为什么暂停"的合理判断，反而比两段悬在半空的项目更好讲——能理性说明取舍本身就体现科研素养。
- **两段在调试的项目定位为"进行中"**：面试时坦诚说 ongoing，重点讲方法思路和你已排除的路径。老师对"做到一半但想得清楚"的接受度，远高于"声称有成果但一问三不知"。
- **停止以"调通方法"为目标投入时间**：如果自然调通了是惊喜，但不把它列入计划。

**2. 面试优先级进一步上升**
- 没有论文 + 科研未出成果，意味着你的申请几乎全靠**面试当场的表现**来定胜负。硬指标（排名、六级、ICPC/CCPC）负责把你送进面试，面试负责录取。
- 机试环节是你的主场优势，用面试/机试风格的高频刷题维持手感即可，不需要为此开新比赛。

**3. 科研梳理的 2.5 成时间具体做什么**
- 为主写一段 200 字以内的问题陈述 + 个人贡献说明；
- 每个项目准备一份"追问清单"：动机、相关工作、你的方法与替代方案、目前卡点、下一步计划；
- 把"在调试"翻译成可讨论的技术语言（调的是什么、怀疑什么、验证了什么），而不是一句"还没做出来"。

## 一句话回答你的问题
时间分配的比例基本不用大动，但科研那部分钱要花在"把已有工作讲得漂亮"上，而不是"赌方法调通"。你的牌面是排名+英语+竞赛底子+三段真实科研经历，面试是把这副牌兑现的唯一渠道。
